# 神经枪战 (neuroshoot)

俯视 2D 战术射击游戏，核心是**神经网络 + 遗传进化**的 AI 对战系统。
libGDX / Java 实现，最低支持 Android 5.1 (API 21)。

## 玩法

五个入口：

| 入口 | 说明 |
|---|---|
| 神经训练 | 四族群并行混战进化，实时看适应度曲线，可保存模型 |
| 人机对练 | 1 真人 + 3 AI 队友 vs 4 AI，或独狼 1 打 4 |
| AI 对练 | 两族 AI 互相对战，可选持续进化 |
| 局域网联机 | UDP 广播发现房间，主机权威同步 |
| 设置 | 按钮大小、摇杆大小、界偏移、昼夜模式 |

## 核心机制

**四族群进化**

每局四个族群各派 2 人混战，按各自倾向打分：

- 击杀族：击杀 × 6 + 伤害 × 0.05 + 瞄准时长
- 生存族：存活秒数 × 1.2 + 活到最后加分
- 躲避族：少受伤 + 与敌人保持距离
- 跑图族：覆盖格子数 + 移动距离

每 4 局繁衍一代，每 5 代做一次筛选：长期垫底的族群清空重组，冠军族群向其余族群注入一半基因。

**战争迷雾**

视野 = 半径 + 朝向扇形 + 视线遮挡三重判定。白天 2560px / 100° 视角，夜晚 430px / 132°，夜视仪可提升到白天的 55%。柱子、墙、箱子都会断开视线。

**多层建筑**

地图按 64px 格子划分楼层，楼梯格踩上去即切换楼层，不同楼层互相看不见也打不到。

**武器系统**

58 把枪械，7 个分类（突击步枪 19 / 冲锋枪 10 / 射手步枪 9 / 手枪 7 / 霰弹枪 5 / 狙击枪 4 / 轻机枪 4），每把枪有独立贴图与数值。

改枪台有 5 个配件槽（瞄具 / 枪口 / 握把 / 弹匣 / 枪托），14 种配件实时影响六项面板数值。

主副武器双持，空弹自动切枪。

**伤病系统**

子弹与爆炸造成流血（持续掉血、留血迹与血脚印，需绷带止血）；爆炸有概率骨折（移速减半，需手术包）；治疗针回血、止痛药免疫恐慌惩罚。

## 构建

```bash
# 容器内一键构建（需要 JDK17 + Gradle 8.9 + Android SDK）
./build.sh

# 或手动
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk
./gradlew :android:assembleRelease
```

产物在 `dist/`。

美术素材由 `tools/gen_art.py` 程序化生成（统一粗黑描边 + 平涂风格），
字体由 `tools/subset_font.py` 按代码用字裁剪。

## 技术要点

- **模拟与渲染分离**：`world/` 包不依赖 libGDX，可在无头环境跑自检
- **BFS 寻路**：46×40 格地图整图搜索开销可忽略，每格只入队一次
- **固定步长推进**：训练按 1/30 秒推进，最高 100 倍速（实测约 120 倍）
- **渲染器隔离**：ShapeRenderer 与 SpriteBatch 不能嵌套 begin/end，弹道线与弹体贴图分开绘制
